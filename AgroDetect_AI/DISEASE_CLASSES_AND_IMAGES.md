## 🎓 Pro Tips for High Confidence

1. **Use images from the Kaggle dataset** - These are what the model was trained on
2. **Focus on distinctive symptoms** - Clear disease patterns
3. **Avoid ambiguous images** - Early stage diseases may have low confidence
4. **Use close-up shots** - Fill the frame with the leaf
5. **Good lighting** - Natural daylight, no shadows
6. **Clear focus** - Sharp, not blurry
7. **Single leaf** - Avoid multiple leaves or complex backgrounds

## 📥 Quick Download Script

Save this as `download_test_images.py`:

```python
import os
import requests

# Sample images from PlantVillage (public domain)
test_images = {
    "tomato_late_blight.jpg": "https://raw.githubusercontent.com/spMohanty/PlantVillage-Dataset/master/raw/color/Tomato___Late_blight/0a5e9323-dbad-432d-ac58-d291718345d9___GHLB2 Leaf 8607.JPG",
    "tomato_healthy.jpg": "https://raw.githubusercontent.com/spMohanty/PlantVillage-Dataset/master/raw/color/Tomato___healthy/0a2a5e1e-4f9f-4e7e-9b0e-8c8c8c8c8c8c___GH_HL Leaf 8.JPG",
}

os.makedirs("test_images", exist_ok=True)

for filename, url in test_images.items():
    try:
        response = requests.get(url)
        with open(f"test_images/{filename}", "wb") as f:
            f.write(response.content)
        print(f"✓ Downloaded: {filename}")
    except:
        print(f"✗ Failed: {filename}")
```
